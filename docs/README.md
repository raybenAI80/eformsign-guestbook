# 이폼사인 방명록 — 안내 문서

태블릿을 로비에 세워 두면 방문자가 직접 서식을 채우고, 다음 사람에게는 빈 서식이 저절로 다시 뜹니다.
이 폴더의 문서는 그 화면을 **직접 설치해서 쓰는 분**을 위한 것입니다. 컴퓨터를 잘 다루지 않아도 따라 할 수 있게 적었습니다.

## 전체 흐름 — 네 걸음

1. 이폼사인 웹폼 디자이너에서 **쓸 서식을 만듭니다.**
2. 그 서식의 **방문자용 작성 주소**를 복사합니다.
3. **설정 마법사**(`setup.html`)에 그 주소를 붙여 넣고, 화면이 시키는 대로 설치합니다.
4. 설치가 끝나면 나오는 **인터넷 주소를 태블릿에 넣습니다.**

## 어떤 문서를 볼까요

| 이 문서 | 이럴 때 봅니다 |
|---|---|
| [처음 설치하기](vercel-signup-guide.md) | 처음 설치할 때. 계정 만들기부터 태블릿에 주소 넣기까지 전부 |
| [매일 아침 기록 받아 보기](report-option.md) | 어제 들어온 기록을 매일 아침 받아 보고 싶을 때(설정 대행 서비스, 유료) |
| [서식을 고쳤을 때](after-form-change.md) | 서식의 칸을 고쳤거나, 다른 서식으로 바꿔 달 때 |
