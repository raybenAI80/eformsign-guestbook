# 이폼사인 방명록 — 일일 리포트 옵션 (유료)

> 환경변수 이름은 **저장소 README 의 환경변수 표를 기준으로 한다.** 이 문서와 README 가 다르면 README 를 따른다.

---

## 무엇이 오나

하루에 한 번, 전날 완료된 문서를 모아 알려 준다. 담을 내용은 다음과 같다.

- 집계 기간(전날 00:00 ~ 23:59)
- 전날 완료된 문서 **건수**
- 문서 **목록** — 문서 제목과 완료 시각

기본 제품에는 이 기능이 없다. 리포트를 켜지 않으면 방문 기록은 이폼사인 콘솔의 **문서 관리** 화면에서 확인한다.

### 이 옵션이 필요한 이유

외부 URL 로 작성된 문서는 담당자의 개인 문서함(진행 중·처리할·완료)에 들어가지 않는다. 방문자가 이폼사인 멤버가 아니기 때문이며, 제품의 문서함 분류 규칙대로 동작하는 것이다. 또 워크플로에 회사 멤버 단계가 없으면 완료 알림 메일의 수신자 후보 자체가 생기지 않는다.

그래서 담당자가 매일 콘솔에 들어가 확인하지 않으려면 별도의 전달 경로가 필요하고, 이 옵션이 그 역할을 한다.

## 켜는 법

Vercel 프로젝트의 **Settings > Environment Variables** 에 아래 값을 넣고 **Redeploy** 한다. 환경변수만 고치고 재배포하지 않으면 반영되지 않는다.

### 공통

| 환경변수 | 값 |
|---|---|
| `KIOSK_REPORT_ENABLED` | `true` |
| `EFORMSIGN_API_KEY` | 이폼사인 콘솔에서 발급한 API 키 (아래 「API 키 발급」 참조) |
| `REPORT_SECRET` | 리포트 실행 경로를 보호하는 임의 문자열. 32자 이상의 무작위 값을 쓴다 |

### 전달 방식 — 둘 중 하나를 고른다

**(가) 웹훅으로 받기** — 사내 메신저나 자체 시스템으로 보낼 때.

| 환경변수 | 값 |
|---|---|
| `REPORT_WEBHOOK_URL` | 리포트를 POST 로 받을 주소 |

**(나) 메일로 받기** — 담당자 메일함으로 보낼 때. 메일 발송 서비스 [Resend](https://resend.com) 계정이 따로 필요하다.

| 환경변수 | 값 |
|---|---|
| `RESEND_API_KEY` | Resend 에서 발급한 키 |
| `REPORT_TO_EMAIL` | 리포트를 받을 메일 주소 |

## API 키 발급

리포트는 이폼사인 Open API 로 전날 문서를 조회한다. 따라서 이폼사인 API 키가 필요하다.

**경로: 이폼사인 콘솔 > [커넥트] > [API / Webhook] > [API 키 관리] 탭 > API 키 생성**[^1]

1. 🔴 **대표 관리자만 발급할 수 있다.** 「메뉴가 보이지 않는다」는 문의의 가장 흔한 원인이 이것이다. 대표 관리자가 아니면 대표 관리자에게 요청한다.
2. 별칭과 애플리케이션 이름을 넣고 저장한다.
3. 목록에서 **「키 보기」** 를 누르면 API 키와 비밀 키가 보인다. 여기서 보이는 **API 키** 를 `EFORMSIGN_API_KEY` 에 넣는다.
4. 비밀 키는 이 옵션에서 쓰지 않는다.

회사 ID(`KIOSK_COMPANY_ID`)는 API 키와 다른 곳에 있다. **[회사 관리] > [회사 정보] > 기본 정보**에서 확인한다(브라우저 주소창의 값이 아니다).

## 키는 어디에 저장되나

`EFORMSIGN_API_KEY` 를 비롯한 모든 환경변수는 **고객의 Vercel 프로젝트에만 저장된다.** 리포트를 만드는 코드도 고객 계정에서 실행된다. 이 값들은 우리에게 전달되지 않고, 우리가 조회할 수도 없다.

키를 다루는 원칙은 다음과 같다.

- 키는 환경변수로만 넣는다. 저장소 파일이나 메신저에 적어 두지 않는다.
- 담당자가 바뀌거나 키가 새어 나갔다고 판단되면 콘솔에서 그 키를 **비활성 또는 삭제**하고 새로 발급한다.
- `REPORT_SECRET` 도 같은 방식으로 다룬다.

## 알아 둘 한계

**하루 한 번이 상한이다.** Vercel 무료(Hobby) 플랜의 크론 작업은 하루 한 번까지만 실행된다(vercel.com/docs/cron-jobs/usage-and-pricing, 2026-09-15 확인).

> "Hobby accounts are limited to cron jobs that run once per day."

같은 문서가 Hobby 의 실행 시각 정밀도를 '시간 단위(±59분)'로 적고 있다. 오전 1시로 지정해도 실제 실행은 1시에서 1시 59분 사이다. 전날 것을 모아 보내는 용도라 이 오차는 문제되지 않지만, **정해진 시각에 받아야 한다면** Vercel Pro 로 올려야 한다. Pro 는 크론을 분 단위로 지정할 수 있다.

**실시간 알림이 아니다.** 방문자가 작성한 즉시 알림이 필요하면 리포트가 아니라 이폼사인 웹훅을 쓰는 별도 연동이 필요하다.

**요금.** 이 옵션은 유료다. 적용 조건은 계약 담당자와 협의한다.
