# 서식을 바꾸거나 다른 서식으로 교체할 때

이 화면은 **어떤 서식이든** 띄웁니다. 회사 ID 와 서식 ID 두 개만 가지고 이폼사인 작성 화면을
그대로 보여 주기 때문에, 서식에 무슨 항목이 몇 개 있는지 화면 쪽은 전혀 모릅니다.
그래서 항목을 고치든 서식을 통째로 갈아끼우든 **화면 파일은 손댈 것이 없습니다.**

경우가 둘입니다.

- **(가) 같은 서식의 항목만 고쳤다** — 항목을 더하거나 지우거나 이름을 바꾼 경우. 1~5번만 봅니다.
- **(나) 다른 서식으로 갈아끼운다** — 서식 자체가 바뀌는 경우. 6번도 함께 봅니다.

---

## (가) 같은 서식의 항목을 고쳤을 때

1. **서식을 다시 발행합니다.** 저장만 하면 태블릿에는 예전 서식이 계속 나옵니다.
2. **「URL로 문서 생성 허용」이 아직 켜져 있는지 봅니다.** 서식을 고쳐 저장하는 과정에서 이 설정이
   꺼지는 일이 있습니다. 꺼져 있으면 방문자 화면에 서식 대신 알 수 없는 오류 창이 뜹니다.
3. **문서 관리 화면의 목록에 보일 항목을 다시 고릅니다.** 새로 넣은 항목은 목록에 저절로 나타나지
   않고, 지운 항목은 빈 칸으로 남습니다. 서식 설정에서 목록에 보일 항목을 다시 고르세요.
   **문서 제목 규칙에 항목 이름을 넣어 두었다면 그 이름도 함께 고칩니다** — 지우거나 이름을 바꾼
   항목을 가리키고 있으면 문서 제목의 그 자리가 조용히 빈 칸이 됩니다.
4. **태블릿 화면을 새로고침합니다.** 바뀐 항목은 자동으로 따라옵니다. 설정 파일(`config.js`)이나
   주소는 건드릴 것이 없습니다.
5. **한 건 작성해 전송해 봅니다.** 이폼사인 콘솔 > 문서 관리에 그 문서가 보이면 끝입니다.
   완료 문서 리포트를 쓰고 있다면 **리포트도 손댈 것이 없습니다** — 표의 열을 서식 항목에서
   그때그때 만들기 때문에 새 항목은 다음 리포트부터 저절로 열로 나옵니다.

## (나) 다른 서식으로 갈아끼울 때

6. **새 서식의 ID 를 설정에 넣습니다.** 설정 마법사를 다시 열어 2단계에 새 서식의 외부 작성 주소를
   붙여 넣으면 됩니다. 마법사가 그 자리에서 서식 조건을 다시 확인해 줍니다. 마법사를 쓰지 않는다면
   `config.js` 의 `templateId` 한 줄만 바꿉니다.
7. **새 서식도 조건 네 가지를 갖췄는지 확인합니다** — 「URL로 문서 생성 허용」켜짐 · 작성 단계가
   하나 · 알림 설정이 비어 있지 않음 · 문서 관리자가 지정됨. 마법사 2단계가 이 넷을 봐 줍니다.
8. **화면 제목도 새 서식에 맞게 바꿉니다.** 마법사 3단계의 「화면 제목」입니다. 비워 두면
   「문서 작성」으로 나옵니다.

### 🔴 같은 서식 파일만 새 파일로 바꿔치기하지 마세요

이폼사인에는 기존 서식의 **파일만** 새 파일로 교체하는 길이 있습니다.
2026-09-16에 실제로 해 보니 **겉보기 항목 이름은 바뀌는데 실제 서식 파일은 그대로였고**,
문서 관리 목록 설정과 문서 제목 규칙은 옛 항목을 그대로 가리키고 있었습니다.
서식을 바꿀 때는 **웹폼 디자이너에서 고쳐 다시 발행**하거나 **새 서식을 만들어 갈아끼우는** 쪽을 쓰세요.

## 실제로 확인한 것

2026-09-16에 구성이 전혀 다른 서식 세 가지를 **같은 화면 파일로** 돌려 봤습니다.
설정에서 서식 ID 만 바꿨고 코드는 한 줄도 고치지 않았습니다.

| 서식 | 들어 있는 것 | 결과 |
|---|---|---|
| 방문자 기록부 | 글자 칸 다섯 · 체크박스 · 날짜 · 서명 | 작성·전송·다음 사람 빈 화면 모두 정상 |
| 항목을 고친 방문자 기록부 | 한 개 추가 · 한 개 이름 변경 · 한 개 삭제 | 정상. 리포트 열도 새 항목으로 따라왔음 |
| 만족도 설문 | 고르는 문항 셋 · 자유 입력 하나. **서명 없음 · 날짜 없음 · 이름 칸 없음** | 정상. **서명 칸이 없어도 전송됩니다** |

## 잘 안 될 때

| 증상 | 먼저 볼 곳 |
|---|---|
| 서식 자리에 「에러코드 1020030013」 창이 뜬다 | 2번 — 「URL로 문서 생성 허용」이 꺼졌습니다 |
| 예전 항목이 그대로 보인다 | 1번 — 다시 발행하지 않았거나 태블릿 화면을 새로고침하지 않았습니다 |
| 문서 관리 목록에 새 항목 칸이 없다 | 3번 — 목록에 보일 항목을 다시 고릅니다 |
| 문서 제목의 한 자리가 빈 칸이다 | 3번 — 제목 규칙이 없어진 항목을 가리키고 있습니다 |
| 서식을 갈아끼웠는데 예전 서식이 뜬다 | 6번 — 설정의 서식 ID 가 아직 예전 것입니다 |
| 리포트에 새 항목 열이 없다 | 그 항목이 들어간 문서가 아직 한 건도 완료되지 않았습니다. 한 건 작성해 보세요 |
