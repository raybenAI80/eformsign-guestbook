## 읽는 법

- **치환 문장**은 사전의 「간단」 템플릿(`prompt_template`)에 우리 소재를 넣은 것이다. 부르는 말은 「하이퍼프레임(HyperFrames)으로」(공통)를 썼다. Remotion 장면에 쓸 때는 부르는 말을 빼고 문장을 컴포넌트 명세로 읽는다. 사전의 「🔍 자세히」(장면 순서 초 단위·모양·하지 말 것)는 catalog.json 의 `prompt_detailed` 에 있다.
- 「」 안 글자는 **확정 카피 그대로** 넣었다(script.ts). 새 카피가 필요한 칸은 `[카피 미확정]` 으로 표시했다 — 렌더하기 전에 표로 사용자 확정을 받아야 한다.
- 파일명(`gen-01.png` 등)은 현재 저장소 자산 이름이거나, 없는 자산이면 `<…>` 로 표시했다.
- **제약 점검** 열: ✅ = 걸리는 제약 없음 · ⚠ = 조건부(조건을 적음) · ❌ = 제약 위반(참고용으로만 남김).
  점검한 제약: ① 헤드라인·자막에 태블릿·설치·키오스크 금지 ② 이폼사인 로고 픽셀 불변(3D 는 로고 주변만) ③ 화면은 이폼사인 정식 기능 UI·이폼사인이 만든 문서만(래퍼 고유 화면·가짜 UI 금지) ④ 도입은 시청자 문제(방명록 수기 작성·직접 관리), 행사·이벤트·전시 같은 장소·시점 특정어 금지 ⑤ 근거 없는 수치 금지.

## 공통 주의(사전 → 우리 프로젝트)

- 사전 문장은 HyperFrames 렌더 계약 기준이다. 자세히 문장의 `[하지 말 것]` 첫머리 「내레이션·음악·효과음 없음」은 우리 영상(나레이션·BGM 있음)에서는 **그래픽 층만** 만든다는 뜻으로 읽고, 오디오는 기존 믹스(check-mix 게이트)에 맡긴다.
- `overlay` 종류(41개)는 「배경 투명 — 영상 위 합성」. Remotion 본편에 끼울 때는 투명 webm 으로 받아 레이어로 얹거나, 같은 명세를 Remotion 컴포넌트로 옮긴다(10-02 HF 이식 시험: 화면 동치는 통과, CPU mp4 렌더 4배 느림·모노 +3dB 미해결).
- 「색은 영상 배경·옷 색에 맞춰 조정해줘」 문구가 F 계열 대부분에 붙어 있다 — 이폼사인 디자인 가이드 색으로 덮어쓰는 지시를 따로 넣어야 한다.
- `[카피 미확정]` 칸은 렌더 전에 카피 표로 확정받는다(카피 규칙: 렌더 뒤 수정 = TTS·장면 길이·줄바꿈 전부 재작업).
