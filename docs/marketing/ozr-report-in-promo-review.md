# 홍보 영상 「관리」 장면에 이폼사인 보고서를 넣을 수 있는가 — 검토

작성 2026-09-23 · 대상: 홍보 영상 Manage 장면(35–46초)의 「리포트」 자리

상품에 따로 만든 리포트 화면(report.html)은 영상에서 뺍니다(2026-09-21 지시). 이 문서는 그 자리를
**이폼사인 자체 수단**으로 채울 수 있는지 검토한 결과입니다. 결론을 정하지 않고, 고를 수 있는 선택지로
정리했습니다. 고르는 것은 사용자 몫입니다.

## 2. 질문별 답

### Q1. 이폼사인 안에, 서버 코드 없이 쓰는 「완료 문서 집계·명단 보고서」 화면이 있는가

**집계 화면은 없습니다. 모아서 내려받는 기능은 있습니다.**

| 기능 | 무엇을 하나 | 근거 |
|---|---|---|
| 완료 문서함 · 문서 관리 → 데이터 파일 생성 | 고른 문서들의 입력값(최대 512개 항목)과 문서 정보(제목·문서 번호·작성자 등)를 표 파일(CSV) 하나로 만든다. 파일 이름과 비밀번호를 정하고, 생성 목록에서 7일 동안 다시 받을 수 있다. 한 화면 최대 100건 | 이폼사인 매뉴얼 8장 「문서 다운로드 → 데이터 파일 다운로드」 |
| 완료 문서함 → 문서 다운로드(PDF) | 문서 여러 건을 PDF로 한 번에 받는다(최대 100건) | 같은 절 「PDF 파일로 다운로드」 |
| 커넥트 → 분석 및 리포팅 | 새 문서가 들어올 때마다 입력값이 구글 시트 · 오피스 365 엑셀에 자동으로 쌓인다. 대표 관리자만 설정 | 매뉴얼 10장 「분석 및 리포팅」 |
| 대시보드 | 바로가기·즐겨찾기 화면. 집계 숫자나 그래프는 없다 | 매뉴얼 2장 「대시보드 화면 구성」 |

촬영 계정에서 실제 화면을 캡처할 수 있는지는 **아직 확인하지 못했습니다.** 확인에 쓰는 캡처용 크롬(로그인
세션을 담은 창)이 이번 검토 시각에 켜져 있지 않았습니다. 로그인은 대신 하지 않았습니다. 09-18 촬영 기록에는
「계정에 리포트 메뉴 없음」 이라고 적혀 있는데, 이것이 「분석 및 리포팅」 메뉴까지 포함한 말인지는 기록만으로는
알 수 없습니다. B를 고르면 촬영 전에 이 메뉴가 보이는지부터 확인해야 합니다.

### Q2. 판매 사례의 OZR 방식을 촬영 계정에서 재현할 수 있는가

**재현은 가능하지만, 사례 그대로 따라 할 이유가 없습니다.**

판매 사례(2023년, 공공 연구기관 납품)는 이렇게 동작했습니다.

1. 담당자가 자기 PC에 자바를 설치하고 작은 프로그램을 켠다.
2. 날짜 하나와 멤버 ID를 넣으면 프로그램이 그날의 방명록 완료 문서를 이폼사인에서 받아 온다.
3. 이폼사인에 로그인하면, 미리 올려 둔 「방명록 리포트」 OZR 서식에 명단이 채워진 작성 화면이 뜬다.
4. 「완료」를 누르면 완료 문서함에 「방명록 리포트_날짜」 문서로 저장된다. 명단은 순번·성명·소속기관·직위
   4칸에, 방문자가 직접 한 서명 그림이 붙는다.

지금 이 PC에서 필요한 것과 있는 것:

| 필요한 것 | 지금 상태 |
|---|---|
| 당시 프로그램 파일 · 보고서 서식 원본 | 없음. 매뉴얼 글과 화면 캡처만 남아 있다 |
| 자바 | 설치돼 있지 않음 |
| OZ 서식 편집 프로그램(OZ e-Form Designer) | 설치돼 있음 |
| 이폼사인 연결 열쇠(API 키) · 멤버 ID | 영상 준비용 설정 파일에 들어 있음(값은 여기 적지 않음) |
| 따로 서버 | 필요 없음(사례도 담당자 PC 에서만 돌았다) |

프로그램을 다시 만들어야 하므로 2~3일 이상 걸립니다(추정). 그런데 영상에 보이는 결과(완료 문서함의 명단 문서)는
C와 똑같습니다. 그래서 D는 C로 대신할 수 있습니다.

### Q3. 「OZR 보고서 = 이폼사인 문서 한 건」 우회(C)는 영상용으로 정당한가

**결과물은 이폼사인 정식 화면입니다. 만드는 단추는 이폼사인에 없습니다.** 둘 다 사실이라 자막으로 구분해야 합니다.

- 이미 있는 도구: 모노레포 도구에 「완료 문서 → 집계 → OZR 서식 생성 → 이폼사인에 올려 문서 생성 → 완료 PDF
  회수 → 정리」를 한 번에 하는 명령이 있습니다(도구 명령 `ozr report`, 같은 기능의 AI 도구도 있음). 표·합계·
  막대 그래프가 이폼사인 서버에서 PDF로 그려지는 것은 이전에 실제로 확인했습니다.
- 영상용으로 바꿔야 할 점(모두 미실측):
  1. 행 내용을 방명록 항목(방문일시·성명·소속·방문목적)으로 바꾼다. 도구에 「행 데이터를 파일로 주는」 입력이
     이미 있어서 서식 쪽만 손보면 된다.
  2. 기본 동작은 끝나면 임시 서식과 문서를 지운다. 영상에서는 문서함에 남아야 하므로 남기는 방식으로 돌린다.
  3. 서명 그림 칸: 이폼사인 목록 조회는 서명 칸 값을 그림이 아니라 표시만 돌려준다. 판매 사례가 서명 그림을
     어떻게 가져왔는지는 매뉴얼에 없다. 서명 칸은 빼고 가거나, 따로 조사가 필요하다.
- 시청자가 보는 것: 이폼사인 완료 문서함 → 이폼사인 문서 화면 → 명단 표. 목업이 아니다.
- 시청자가 오해할 수 있는 것: 「이폼사인에서 단추 하나로 명단 보고서가 나온다」. 실제로는 보고서 서식을
  맞춤 제작하고 API로 만든다. 그래서 자막에 *보고서 서식은 맞춤 제작(OZ Report)* 같은 각주가 필요하다.
  별도 서버는 필요 없지만, 고객이 이것을 쓰려면 연결 열쇠(API 키)와 우리 도구(또는 우리 쪽 제작 지원)가 필요하다.

### Q4. 결론 표 해설

- **(가) 지금 가능**: A. 이폼사인 매뉴얼에 있는 정식 기능이라 어느 계정에서나 같은 화면이다. 다만 「보고서」
  라기보다 「표 파일 내려받기」 다.
- **(나) 준비 후 가능**: B(계정 연결 1~2시간, 메뉴 노출 확인 먼저), C(반나절~1일, 서명 칸은 미확인),
  D(2~3일 이상, C와 결과 같음).
- **(다) 불가·비권장**: E(우리 화면이고 서버 필요 여부 미결), F(이런 화면이 이폼사인에 없음).

「문서가 모이면 보고서까지」 라는 메시지를 문자 그대로 살리는 것은 C 뿐입니다. A는 「표 파일로」, B는
「엑셀·시트로」로 메시지를 바꿔야 합니다.

## 3. 사용자가 정해 줄 것

1. A · B · C 중 무엇을 넣을지(여러 개 가능), 또는 「리포트 자리를 비우고 문서함 · 검색 · PDF만」으로 둘지.
2. C를 고르면: 서명 그림 칸을 뺀 명단으로 갈지, 서명 칸 조사를 먼저 할지.
3. B를 고르면: 촬영 계정에 구글 또는 마이크로소프트 계정을 연결해도 되는지.

고르기 전까지 Manage 장면은 문서함 · 검색 · PDF 미리보기만 씁니다.
