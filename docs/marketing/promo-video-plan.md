## 1. 한 줄 요약

**"방문자 기록도 이폼사인. 서식을 만들고, 사람이 안 있어도 문서가 쌓이고, 바로 관리됩니다."**

이폼사인의 세 가지 힘(서식 제작 → 누구나 작성 → 문서 자동 보관·관리)을 방명록이라는 **가장 가벼운 사례**로 60초 안에 보여 준다. 마지막 메시지는 「방명록은 시작일 뿐, 계약서·동의서·신청서도 같은 이폼사인」이며 CTA 는 **이폼사인 체험·문의**다. 60초 본편 1개 + 15초 컷다운 2개(세로·가로).

## 3. 핵심 메시지 (우선순위 순)

1. **이폼사인이면 서식은 뭐든** — 웹폼 디자이너로 방명록도, 동의서도, 신청서도 만든다. 고정 양식이 없다.
2. **로그인 없는 누구나 작성** — 회원이 아닌 방문자·고객이 바로 채우고 전송한다(외부 작성).
3. **사람이 없어도 문서가 쌓인다** — 제출 즉시 이폼사인 문서함에 완료 문서로 보관. 검색·PDF·리포트로 바로 관리.
4. **종이보다 안전** — 앞사람 개인정보가 다음 사람에게 보이지 않는다. 이폼사인이 보관한다.
5. **방명록은 시작일 뿐** — 같은 방식으로 계약·동의·접수 전부. (전이 메시지, 결말 전용)

방명록 래퍼의 기능(자동 복귀·설치 마법사)은 **메시지 2·3을 보여 주는 장치**로만 등장한다. 「태블릿」 「설치가 쉽다」는 자막 헤드라인으로 쓰지 않는다.

```
  public/voice/             # edge-tts mp3 + 길이 JSON(장면 길이 = 음성 길이 + 여유)
  tools/capture.mjs         # 9223 프로필로 실화면 캡처
  tools/gen-images.md       # gpt-image 프롬프트 6개 + 일관성 조건(재생성 시 동일 조건)
  tools/tts.mjs             # script.ts → mp3 일괄 생성
  tools/check.mjs           # 게이트: 쉬운 말 · 브랜드 색 · 로고 텍스트 조판 검출 · ID 노출 grep · 줄바꿈
```

함정(정본에서 가져옴): `typescript@5` 고정(7 불가) · 장면 길이는 TTS 길이에서 역산 · 생성 이미지는 프롬프트·시드를 함께 저장(재생성 가능) · 렌더는 백그라운드 실행(포그라운드 2분 제한).

## 8. 비용 구조

외부 지출은 **음원 라이선스 1건**만(생성 이미지는 기존 ChatGPT 구독으로 해결). 나머지는 내부 작업 시간(코드·리뷰). 성우 없이 edge-tts 로 완결하되, 최종본만 성우 교체 여지를 둔다(음성 파일 교체만으로 가능한 구조). **영상에 가격을 넣지 않으므로 가격 변경 시 재제작 불필요.**

## 10. 반드시 지킬 제약(제품·법·저장소)

1. **주인공은 이폼사인.** 자막 헤드라인에 「태블릿」 「설치」 「무인 키오스크」를 쓰지 않는다. 장비·래퍼는 화면에 보일 뿐 말로 팔지 않는다.
1-1. **생성형 이미지 경계**: 이폼사인 화면·로고·슬로건·문서는 절대 생성하지 않는다(실캡처·제공 PNG 만). 생성 이미지 안의 글자는 쓰지 않고 Remotion 텍스트로 덧씌운다. 실존 인물 유사·얼굴 정면 클로즈업 회피. 게시 시 「일부 장면은 생성형 이미지」 고지 문구를 설명란에 넣는다.
2. **회사 ID·서식 ID·실데이터 노출 0.** 영상 전용 데모 계정·서식·가짜 데이터. 이 저장소는 public 이므로 촬영 원본·데모 정보는 데모 저장소 쪽에 둔다.
3. **전송 팝업 2회는 제품 동작**이다. 편집으로 지우지 않는다.
4. 「무료」 「무료로 충분」 표현 금지(Vercel 무료 요금제는 비상업 개인 한정).
5. **가격 숫자·암시 금지.** 리포트는 「유료 옵션」 각주까지만.
6. 자막에 개발자 용어 금지. 원고는 `tools/check-plain-language.mjs` 게이트에 통과시킨다.
7. 자동 제출 방지(reCAPTCHA)는 켠 상태·끈 상태 중 하나로 통일하고 과장하지 않는다.
8. 인증서 기반 전자서명 장면 제외(외부 작성과 병용 불가).
9. 출연자 초상권·음원·폰트 라이선스 확보. 출연 동의는 이폼사인으로 받아 기록을 남긴다.
