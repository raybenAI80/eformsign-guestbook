방명록 디자인 방향 3종

한 장에 10명이 차례로 적는 누적형 방명록입니다. 방향마다 태블릿에서 두 번째 방문자가 보는 화면과, 두 명이 적은 뒤 받는 A4 완료 PDF를 나란히 그렸습니다.

화면 = 덮개·강조가 보이는 입력 상태
PDF = 덮개·강조가 빠진 인쇄 상태
글꼴은 모두 맑은 고딕
추천: 방향 1을 뼈대로 쓰고 방문 목적만 방향 2의 체크 칸으로 바꾸는 조합이 구현 위험 대비 개선 폭이 가장 큽니다. 선택은 사용자 판단입니다.

기관명·날짜·장 번호·방문 시각은 문서를 만들 때 자동으로 채우는 값입니다. 로고를 OZR에 넣는 방식(빌드할 때 이미지로 삽입할지, 문서를 만들 때 값으로 넘길지)은 별도로 조사 중입니다.
