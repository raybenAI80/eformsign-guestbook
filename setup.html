이폼사인 방명록 설정 마법사

방명록 서식은 이폼사인이 제공하는 템플릿을 그대로 쓰거나, 웹폼 디자이너로 원하는 양식을 직접 만들어 쓰면 됩니다.
서식 주소를 붙여 넣으면 나머지는 이 화면이 만들어 드립니다. 입력한 내용은 이 브라우저 안에만 남고 어디로도 보내지 않습니다.

지금 몇 번째인지

    11단계. 서식 주소 붙여넣기

    이폼사인 템플릿을 쓰거나 웹폼 디자이너로 만든 서식이면 됩니다. 서식 설정에서 「URL로 문서 생성 허용」을 켜면 작성 주소가 나옵니다. 그 주소를 아래에 붙여 넣으세요. 나머지는 자동으로 읽어 냅니다.

    안 돼요

    서식이 아직 없어요 → 이폼사인에서 템플릿을 가져오거나 웹폼 디자이너로 만든 뒤 발행하세요.

    자세히
    회사 ID
    서식 ID
    국가 코드
    언어 코드

    22단계. 서식이 열리는지 확인

    아래 화면에 방문자가 볼 작성 서식이 그대로 떠야 합니다. 내용이 보이지 않거나 「보고서를 로딩하면서 예외가 발생했습니다」가 뜨면 서식 설정의 「URL로 문서 생성 허용」이 꺼져 있는 것입니다.

    서식에 봇 방지(로봇이 아닙니다)를 켜 두면
    전송할 때 체크가 한 번 더 뜹니다.
    사람이 지키지 않는 화면이면 꺼 두는 편이 편합니다.

    확인했습니다. 다음 단계로 넘어가세요.
    이폼사인 화면에서 서식 설정 > 워크플로우 > 시작 단계 속성 > 「URL로 문서 생성 허용」을 켜고 서식을 다시 내보낸 뒤, 이 화면을 새로 고쳐 다시 확인해 주세요. 이 설정이 꺼져 있으면 서식을 받아오는 요청이 거부되어 빈 화면만 보입니다.

    33단계. 회사 이름과 로고 넣기

    로고를 올리면 방명록 화면 왼쪽 위에 표시됩니다. 로고가 없으면 회사 이름이 대신 나옵니다. 올린 그림은 작게 줄여서 설정에 함께 담습니다.

    로고 그림이 커서 이 방법으로는 넣을 수 없습니다. 아래 둘 중 하나를 고르세요.

    회사 홈페이지에 이미 올라가 있는 로고 그림을 오른쪽 버튼으로 눌러 「이미지 주소 복사」 한 값을 붙여 넣으세요.

    로고 없이 회사 이름으로 표시합니다.

    44단계. 화면에 보일 글 정하기

    방문자가 태블릿에서 보게 될 제목과 안내 문구입니다. 비워 두면 기본 문구가 그대로 나옵니다.

    55단계. 전송을 누른 뒤 무엇을 할지 고르기

    방문자가 전송을 누른 뒤 곧바로 새 서식을 열지, 감사 인사를 잠시 보여 준 뒤 열지 고릅니다.

    4~6초를 권합니다.
    제출 뒤 동작이 「감사 화면」일 때만 쓰입니다.

    66단계. 처음 화면으로 되돌리는 시간 정하기

    아무도 손대지 않거나 작성하다 자리를 뜬 화면을 언제 처음으로 되돌릴지 정합니다. 현장에 맞춰 조정하세요.

    아무도 손대지 않은 화면을
    처음으로 되돌리기까지의 시간입니다.
    로비나 전시 부스는 60~90초,
    사무실 접수대는 180초를 권합니다.
    0이면 되돌리지 않습니다.

    작성을 시작한 방문자가
    자리를 뜬 경우의 기준입니다.
    빈 화면 방치보다 길게 두세요.

    되돌리기 직전에
    「계속 작성하시겠습니까?」를 보여 주는 시간입니다.
    5~10초를 권합니다.
    눈이 잘 보이지 않거나 글을 읽는 데 시간이 걸리는 방문자가 있으면 20초 이상으로 넉넉히 두세요.

    77단계. 내가 정한 설정 요약

    아래 내용이 맞으면 설치를 시작하세요. 고칠 것이 있으면 아래 「이전」을 눌러 되돌아가 바꾸면 됩니다.

    계정을 새로 만들고 화면을 따라가면 10분 안에 끝납니다.
    먼저 무료 요금제로 설치해 보세요. 회사 업무로 계속 쓰기로 하면 필요에 따라 유료 요금제(Pro, 한 사람 월 20달러)로 바꾸거나, IT 담당자가 있으면 아래 접힌 칸에서 회사 서버에 올리는 방법을 고를 수도 있습니다.
    Vercel은 무료 요금제를 개인 용도로 정해 두었고, 이 비용은 Vercel에 직접 내며 방명록 이용료와는 별개입니다.

    회사 안 서버에 직접 올리고 싶습니다 — IT 담당자에게 전달

    회사에 이미 웹 서버가 있고
    IT 담당자가 직접 올리는 경우입니다.
    아래 파일 묶음과 안내문을 담당자에게 보내 주세요.
