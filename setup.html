1서식 주소 붙여넣기

2서식이 열리는지 확인

아래 화면에 방문자가 볼 작성 서식이 그대로 떠야 합니다. 내용이 보이지 않거나 「보고서를 로딩하면서 예외가 발생했습니다」가 뜨면 서식 설정의 「URL로 문서 생성 허용」이 꺼져 있는 것입니다.

확인했습니다. 다음 단계로 넘어가세요.
이폼사인 화면에서 서식 설정 > 워크플로우 > 시작 단계 속성 > 「URL로 문서 생성 허용」을 켜고 서식을 다시 내보낸 뒤, 이 화면을 새로 고쳐 다시 확인해 주세요. 이 설정이 꺼져 있으면 서식을 받아오는 요청이 거부되어 빈 화면만 보입니다.

3회사 이름과 로고, 안내 문구

로고를 올리면 방명록 화면 왼쪽 위에 표시됩니다. 로고가 없으면 회사 이름이 대신 나옵니다. 올린 그림은 높이 160px 이하로 줄여서 설정에 함께 담습니다.

로고 그림이 커서 이 방법으로는 넣을 수 없습니다. 아래 둘 중 하나를 고르세요.

회사 홈페이지에 이미 올라가 있는 로고 그림을 오른쪽 버튼으로 눌러 「이미지 주소 복사」 한 값을 붙여 넣으세요.

로고 없이 회사 이름으로 표시합니다.

4제출 뒤 동작과 대기시간

방문자가 전송을 누른 뒤 곧바로 새 서식을 열지, 감사 인사를 잠시 보여 준 뒤 열지 고릅니다. 대기시간은 현장에 맞춰 조정하세요.

권장 4~6초. 제출 뒤 동작이 「감사 화면」일 때만 쓰입니다.

아무도 손대지 않은 화면을 처음으로 되돌리기까지의 시간. 로비나 전시 부스는 60~90초, 사무실 접수대는 180초를 권합니다. 0 이면 되돌리지 않습니다.

작성을 시작한 방문자가 자리를 뜬 경우의 기준. 빈 화면 방치보다 길게 두세요.

되돌리기 직전 「계속 작성하시겠습니까?」를 보여 주는 시간. 5~10초를 권합니다.

5내가 정한 설정 요약

아래 내용이 맞으면 설치를 시작하세요. 고칠 것이 있으면 위로 올라가 바꾸면 됩니다.

계정을 새로 만들고 화면을 따라가면 10분 안에 끝납니다. 돈은 들지 않습니다(회사 업무로 상시 쓰면 유료 요금제가 필요합니다).

회사 안 서버에 직접 올리고 싶습니다 — IT 담당자에게 전달

회사에 이미 웹 서버가 있고 IT 담당자가 직접 올리는 경우입니다. 아래 파일 묶음과 안내문을 담당자에게 보내 주세요.
