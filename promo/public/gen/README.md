# public/gen — 생성형 실사 이미지 자리

여기 있는 `gen-01.png` … `gen-06.png` 는 **회색 플레이스홀더**다.
실이미지가 도착하면 **파일만 같은 이름으로 덮어쓰면** 장면이 그대로 붙는다(코드 수정 없음).

| 파일 | 내용 (기획서 6절 소재 ②) | 쓰이는 장면 |
|---|---|---|
| gen-01.png | 행사장 접수대, 종이 방명록에 줄 선 사람들 | Paper (3–9초) |
| gen-02.png | 밤 사무실, 담당자가 종이를 보며 옮겨 적는 모습 | Paper (3–9초) |
| gen-03.png | 접수대 화면 앞에 선 방문자 (화면은 빈 밝은 회색) | Fill (15–27초) |
| gen-04.png | 다른 방문자 A (화면은 빈 밝은 회색) | Repeat (27–35초) |
| gen-05.png | 다른 방문자 B (화면은 빈 밝은 회색) | Repeat (27–35초) |
| gen-06.png | 담당자 노트북 앞 밝은 사무실 (화면은 빈 밝은 회색) | Manage (35–47초) |

공통 조건: 사진 실사 톤, 자연광, 한국 사무·행사 배경, 낮은 채도, 동일 인물·조명·색온도 유지.
🔴 기기 화면은 **빈 밝은 회색**으로 받는다(실캡처 합성 자리).
🔴 로고·글자·브랜드 요소는 생성하지 않는다. 화면에 보이는 글자는 전부 Remotion 으로 얹는다.
🔴 실존 인물과 닮지 않게, 얼굴 정면 클로즈업은 피한다.

프롬프트와 시드는 `tools/gen-images.md` 에 기록한다(재생성 가능해야 한다).
세로 컷다운용 9:16 변형은 `gen-0N-v.png` 로 같은 폴더에 둔다.
